# Журнал создания Play to Grow

Этот файл ведется при каждом существенном изменении проекта. Он фиксирует решения, выполненные работы и ограничения текущей версии.

## 30 октября 2026 — двуязычные страницы для поиска, агентов и LLM

- Русская посадочная страница осталась канонической на `playtogrow.ru`; английская посадочная получила статический адрес `playtogrow.online/en/`. Переключатель RU/EN теперь ведет между реальными HTML-страницами, а не подменяет весь текст JavaScript.
- Созданы 11 пар русских и английских информационных страниц: о проекте, принцип работы, материалы для родителей, детей и психологов, условия пилота, методика и официальные источники, безопасность и данные, контакты, FAQ и обновления.
- На всех индексируемых страницах добавлены уникальные title/description, canonical, взаимные hreflang, Open Graph, разрешение развернутых сниппетов и JSON-LD. FAQ содержит видимые вопросы и соответствующую разметку `FAQPage`.
- Добавлены доменные `robots.txt` и `sitemap.xml`, `llms.txt`, `llms-full.txt`, русский и английский RSS, а также публичный ключ IndexNow. Поисковые роботы OpenAI, Anthropic и Perplexity разрешены; обучающие `GPTBot`, `ClaudeBot` и `Google-Extended` запрещены до отдельного решения владельца.
- `demo.html` исключен из индексации через `noindex,follow`, но остается доступен по ссылкам. Карты сайта содержат только канонические информационные страницы.
- Добавлен генератор `scripts/build_discovery.py`, который создает английскую посадочную и все служебные страницы. Сборка останавливается при отсутствии английского перевода нового блока. `scripts/notify_indexnow.py` отправляет URL обоих доменов после успешного GitHub Pages deploy.
- Добавлены автоматические проверки языковых пар, canonical/hreflang, robots, sitemap, JSON-LD и политики демо. Версия ресурсов повышена до `20261030-1`.
- Локальная проверка: 20/20 тестов, синтаксис JavaScript/Python, сухой прогон IndexNow и оба архива GitHub Pages. В видимой Opera проверены русская и английская посадочные, английская страница методики, переход в английское демо и возврат по логотипу.

## 26 октября 2026 — исходные материалы и направление проекта

- Проанализированы документы автора, история Git и прежние прототипы.
- Определена цель: использовать интерес ребенка к компьютерным играм как мотивацию для выполнения согласованных заданий в реальной жизни.
- Определены три участника: ребенок, родитель и модератор.
- Выбраны название **Play to Grow** и основной слоган **«Играй, чтобы расти»**.
- Выбраны домены: `playtogrow.ru` для русской версии и `playtogrow.online` для английской.
- Backend, отдельные учетные записи и Telegram-бот отложены до появления первых семей и специалистов. Первая версия остается статической и работает на одном устройстве.

## 26 октября 2026 — первая версия сайта

- Создана двуязычная посадочная страница для набора семей и профессионального диалога с психологами.
- Добавлено прямое сообщение о поиске пациентов и семей для работы с компьютерной и игровой зависимостью.
- Добавлено прозрачное описание финансирования: средства родителей на пилотном этапе идут только на разработку, инфраструктуру и развитие проекта; автор не получает личной прибыли до ввода платформы в эксплуатацию.
- Добавлены публичные контакты автора: Telegram, электронная почта и телефон.
- Интерактивная демонстрация вынесена на отдельную страницу. В ней можно переключаться между ролями ребенка, родителя и модератора.
- Реализованы задания, отчеты, проверка результата, начисление баллов, запрос и подтверждение награды, семейные лимиты и демонстрационный прогресс.
- Русский и английский интерфейсы собираются из одного набора исходников.

## 26 октября 2026 — конкретизация текста и доступность

- Удалены абстрактные призывы «Прокачивай себя» и «Открывай больше».
- Для ребенка явно описана механика: выбрать задание, выполнить его, отправить отчет, получить баллы и запросить согласованную игровую награду.
- Для родителя и модератора перечислены конкретные действия в соответствующих кабинетах.
- Исправлен светлый текст на светло-желтой кнопке и усилен контраст текста на пастельных карточках.
- Настольная и мобильная версии проверены в браузере; видимый текст проверен на минимальный контраст 4,5:1.

## 26 октября 2026 — подключение GitHub Pages

- Созданы и подключены два пустых репозитория:
  - `https://github.com/MaximGorskiy/playtogrow.ru`
  - `https://github.com/MaximGorskiy/playtogrow.online`
- Принята схема «один исходный проект — две публикации». Функции и оформление одинаковы; отличаются только язык по умолчанию и метаданные страницы.
- Для `playtogrow.ru` языком по умолчанию назначен русский.
- Для `playtogrow.online` языком по умолчанию назначен английский.
- Публикация выполняется через GitHub Actions из каталога `docs/`.
- Первый запуск workflow подтвердил, что в новых пустых репозиториях GitHub Pages еще не включен. В `actions/configure-pages` добавлен параметр `enablement: true`.
- GitHub не разрешил `GITHUB_TOKEN` впервые создать Pages-сайт (`Resource not accessible by integration`), поэтому Pages был включен через GitHub REST API с авторизацией владельца. Для `playtogrow.online` прежний режим `legacy` заменен на `workflow`.
- Повторные запуски GitHub Actions завершились успешно:
  - русская версия: `https://maximgorskiy.github.io/playtogrow.ru/`;
  - английская версия: `https://playtogrow.online/`.
- Для `playtogrow.online` включено обязательное HTTPS-соединение.
- Домен `playtogrow.ru` пока отвечает страницей регистратора и не привязан к GitHub Pages. После обновления DNS его можно будет подключить без изменения исходного кода.

## 26 октября 2026 — уточнение русскоязычного описания

- Интерес к играм описан как движущая сила развития ребенка.
- В прохождении квеста отдельно обозначена публикация ребенком своих результатов.
- Анализ динамики и планирование улучшений связаны с совместной работой с психологом.
- В роли родителя оставлены подтверждение отчета, подтверждение выдачи награды и финансовое участие в развитии проекта.
- Роль модератора уточнена как внесение профессиональных знаний психолога в квесты, постоянный анализ прогресса ребенка и контроль процесса.

## 26 октября 2026 — подключение домена playtogrow.ru

- Домен `playtogrow.ru` назначен пользовательским доменом русской версии в GitHub Pages.
- Источник публикации сохранен в современном режиме `workflow`: сайт собирается и публикуется через GitHub Actions, поэтому файл `CNAME` в репозитории не требуется.
- Повторная публикация GitHub Actions завершилась успешно: `https://github.com/MaximGorskiy/playtogrow.ru/actions/runs/40315798663`.
- В настройках GitHub Pages включено обязательное HTTPS-соединение (`https_enforced: true`).
- Cloudflare DNS-over-HTTPS уже возвращает четыре адреса GitHub Pages для корневого домена и `www.playtogrow.ru` → `maximgorskiy.github.io`.
- Некоторые публичные и локальные DNS-кэши во время проверки еще возвращали прежний адрес парковочной страницы `95.163.244.138`; окончательное переключение зависит от истечения DNS-кэша.

## 26 октября 2026 — единая русскоязычная версия на двух доменах

- Русскоязычная версия назначена основной для дальнейшей разработки.
- `playtogrow.ru` и `playtogrow.online` синхронизированы как одинаковые публикации с русским языком по умолчанию.
- Переключатель RU/EN сохранен на обоих доменах, поэтому английский интерфейс остается доступен пользователю вручную.
- Сборщик изменен так, чтобы оба GitHub Pages-архива создавались из одинакового русскоязычного HTML.
- Устаревший файл `CNAME` удален из репозитория `playtogrow.online`: при публикации через GitHub Actions пользовательский домен хранится в настройках Pages, а файл не используется.

## 26 октября 2026 — исправление переключения RU/EN

- Устранен переход между доменами при выборе языка: после назначения русского языка основным такой переход всегда возвращал русскую версию.
- Переключатель RU/EN теперь меняет язык внутри текущего домена, отражает выбор в параметре `lang` и сохраняет его в браузере.
- Переход с посадочной страницы в демоверсию передает выбранный язык.
- Английский текст посадочной страницы синхронизирован с последними изменениями русской версии.
- Русский слоган в английском футере и стандартные демонстрационные имена заменены английскими вариантами отображения; пользовательские данные при этом не изменяются.
- В верхней строке демоверсии перед «Мое пространство / My space» добавлена ссылка «Стартовая / Home», которая возвращает на посадочную страницу с сохранением языка.
- К адресам CSS и JavaScript добавлена версия, чтобы после публикации GitHub Pages браузер не продолжал использовать прежнюю логику переключателя из CDN-кэша.
- Версия также передается в ссылках между посадочной страницей и демо, чтобы переход не открывал ранее закэшированный HTML.

## 26 октября 2026 — текущая роль в навигационной строке демо

- Общее обозначение «Мое пространство / My space» заменено названием выбранной роли.
- Навигационная строка теперь строится как «Стартовая / Ребенок / Мой день», «Стартовая / Родитель / Обзор» или «Стартовая / Модератор / План развития» и автоматически переводится на английский.
- Версия ресурсов повышена до `20261026-3`, чтобы изменение сразу появилось после публикации.

## 26 октября 2026 — возврат на стартовую страницу по логотипу

- Логотип Play to Grow в левом верхнем углу демоверсии теперь всегда ведет на стартовую страницу.
- При переходе сохраняется выбранный язык интерфейса.
- Версия ресурсов повышена до `20261026-4`, чтобы браузер и CDN не использовали прежний JavaScript из кэша.

## 30 октября 2026 — новые тезисы раздела «Как работает идея»

- По прямому решению владельца три прежних шага «Выбираем цель», «Проходим квест» и «Отмечаем прогресс» заменены тезисами о выгоде для ребенка, родителя и специалиста.
- Заголовок раздела уточнен: «Не отбирать игру, а сделать ее мостом к росту и взаимопониманию. Что получает каждый участник:»; английская версия передает тот же смысл.
- Русские карточки теперь говорят: ребенок играет в любимые игры столько, сколько хочет, и даже больше; родитель получает развитие ребенка и повышение его внеигровых достижений и навыков; психолог и модератор вместе ищут точки роста маленького пациента.
- Добавлены согласованные английские версии этих трех карточек; генератор обновил английскую посадочную страницу.
- Изменение затрагивает только текст карточек на главной странице. Механика демо, семейные лимиты, награды и ограничения проекта не менялись.
- Известное смысловое напряжение: фраза о времени «сколько хочет, и даже больше» может восприниматься как обещание неограниченной игры и расходится с существующим в демо механизмом семейных лимитов. Текст сохранен в формулировке владельца; при проверке на семьях нужно отдельно оценить реакцию родителей и психологов.

## Текущие ограничения

- Переключение трех ролей в демоверсии не является авторизацией.
- Данные сохраняются только в браузере пользователя и не синхронизируются между устройствами.
- Сайт не подключается к играм, не покупает внутриигровую валюту и не контролирует экранное время автоматически.
- Проект не является медицинской диагностикой или лечением и не обещает гарантированного результата.
